## What is A-Dev?
**A-Dev (Augmented Development)** is a discipline-first framework for the **Solo Architect** to orchestrate AI agents. It replaces the "coordination tax" of large teams with living baselines, **50/50 quality cycles**, and strict **evidence trails**.

Instead of treating AI as a "junior coder" that creates technical debt, A-Dev treats AI as a force multiplier that must be governed by a "Living Baseline" of non-negotiable rules.

## The Core Concept
The **Solo Architect** governs the system using three tools:
1.  **Living Baseline 🛡️**: A repository of constraints (SSR-first, No-Plan-B, Security-by-Default) that every AI prompt must read.
2.  **50/50 Quality Cycle ⚡**: Half the time is spent creating, half verifying (Build → Run → Walkthrough).
3.  **Traceability**: Every feature links to a Plan, a Prompt, and Evidence (Commit/Test).
