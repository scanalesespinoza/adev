# A-Dev

A-Dev is a vendor-neutral framework and implementation model for agent-native software delivery. Its canonical content now lives under [`framework/`](framework/README.md); [`implementation/`](implementation/README.md) turns that canon into consumable contracts, profiles, and operating patterns for autonomous and mixed delivery systems.

## Start here

- People learning the practice: [framework/README.md](framework/README.md).
- Agents adopting the practice: [implementation/AGENTS.md](implementation/AGENTS.md).
- Maintainers and agents working in this repository: [AGENTS.md](AGENTS.md).

The root remains a stable entry point for installed skills and existing links. It does not duplicate the framework canon.
