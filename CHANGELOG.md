# Changelog

All notable changes to A-Dev are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html) from v3.0.0.

## [Unreleased]

### Added
- Evidence-status blocks in every case study, with pinned Homedir artifacts (#128).
- Hardness validation in CI, with cross-platform script paths (#124 port).
- Community health files: contributing guide, code of conduct, security policy, issue and pull request templates, including a pattern-proposal template (#98 port).
- Candidate patterns from operational workflow telemetry (#38 port).

### Changed
- CI hardening: read-only tokens by default, actions pinned by SHA, concurrency, pinned site toolchain, and Dependabot (#122 port).
- Canonical naming "AI Agentic Development" on the site home page (#116 port).

## [3.0.0] - 2026-11-21

A single, installable entry point with a small core doctrine, baseline profiles, an engineering baseline, and a learning loop. See the [release notes](https://github.com/scanalesespinoza/adev/releases/tag/v3.0.0).

### Fixed after release
- Learner path, academic overlay, and a reliable learning loop (#139).

## Book releases before v3.0.0

Releases v1.0.0 to v2.0.0-en were book editions. The book and its history now live in [adev-book](https://github.com/scanalesespinoza/adev-book); the release artifacts remain on this repository's tags.

- **v2.0.0-en** (2026-08-17): first English edition, adapted from the Spanish v2.0.0 manuscript.
- **v2.0.0** (2026-08-17): consolidated Spanish first edition.
- **v1.0.0 to v1.0.5** (2026-01-21 to 2026-06-09): initial public book and framework releases and refinements.
