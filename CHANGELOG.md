# Changelog

All notable changes to the A-Dev repository are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html)
for book releases.

## [v2.0.0-en] - 2026-08-17

### Added
- First English edition of the ADEV book, adapted from the Spanish v2.0.0 manuscript.
- English PDF (`adev-book-en.pdf`) and EPUB (`adev-book-en.epub`) release artifacts.
- English build workflow (`.github/workflows/build-book-en.yml`).
- English appendices: technical assets, glossary, evidence and method.

## [v2.0.0] - 2026-08-17

### Added
- Consolidated Spanish first edition with 15 numbered chapters and 3 appendices.
- Spanish PDF (`adev-book.pdf`) and EPUB (`adev-book.epub`) release artifacts.
- Spanish cover artwork and deterministic cover composition.
- Spanish EPUB build with external-link normalization and EPUBCheck validation.

### Changed
- Migrated the publication workflow from the historical English manifest to `book-es/Book.txt`.
- Set consolidated edition version to v2.0.0.
