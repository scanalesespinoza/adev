# Speaker notes

1. **Hook (1–2 min):** share the shift from relying on search to operating with a baseline. Emphasize AI as engine, you as director.
2. **Problem (3 min):** speed without discipline creates debt and distrust. Introduce quality density.
3. **Method (6–8 min):** explain Atomic Iterations (definition → implementation → verification → evidence) and how the baseline reduces friction.
4. **Evidence (4–5 min):** show the chain plan → prompt → commit → CI. Illustrate how "stop the line" prevents technical debt.
5. **Vision (3 min):** HomeDir as a public profile of contribution and traceability.
6. **Closing (2 min):** invite to the "Weekend Marathon" and repeat the core phrase: discipline + real efficiency.
