# Reference Skills

These skills are vendor-neutral reference contracts for agents that consume A-Dev from this repository. They are not installed runtimes and do not grant permissions by themselves.

- [`adev-read-only-inspection`](adev-read-only-inspection/SKILL.md): inspect the A-Dev canon and return a bounded, evidence-aware report without changing local or remote state.

Start with the [agent consumption guide](../06-agent-consumption-guide.md) before selecting a skill.
