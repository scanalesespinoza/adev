# Practices

Practices are repeatable patterns that help teams apply doctrine in context. They are guidance unless a project policy explicitly promotes them to a requirement.

Current practice assets:

- [`QUALITY.md`](../../QUALITY.md): the 50/50 build and verification cycle.
- [`starter-kit/OPERATING_RITUALS.md`](../../starter-kit/OPERATING_RITUALS.md): pre-iteration, recovery, multilingual, performance, and disaster-recovery rituals.
- [`starter-kit/FIRST_WEEK.md`](../../starter-kit/FIRST_WEEK.md): the first evidence-backed delivery loop.

Stack-specific values, endpoints, resource limits, and deployment choices should be examples or project overlays rather than universal doctrine.
