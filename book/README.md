# A-Dev Book

This directory is the canonical entry point for the book that explains the A-Dev practice. The normative practice itself is mapped under [`framework/`](../framework/README.md).

## Current book sources

- [`adevelopment-book/book/`](../adevelopment-book/book/) contains the current chapter and appendix sources used by the PDF and documentation workflows.
- [`adevelopment-book/collateral/`](../adevelopment-book/collateral/) contains talk, post, one-pager, and video material derived from the book.
- [`publishing-kit/`](../publishing-kit/) contains proposal, readiness, rights, market, and expansion planning.

## Historical manuscript snapshot

[`manuscript/`](../manuscript/) is a second, partially divergent manuscript snapshot. It is preserved for provenance, but it is not the declared build source. Do not edit both trees in parallel.

A later, dedicated consolidation phase should compare unique content, merge anything still valuable into `adevelopment-book/book/`, update workflows, and then replace the historical tree with an explicit archive or redirect.
