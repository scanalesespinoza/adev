# Publishing Kit

Editorial, positioning, and release-planning assets for the ADEV book. These documents support publication work; they are not normative framework doctrine.

## Conventions

- Files are numbered `NN-name.md` in rough pipeline order (inventory → proposal → readiness → edition tracks). The number is an ordering aid, not a dependency graph; ordinals are unique and may skip.
- Documents fall into two classes:
  - **Dated records** — snapshots and decisions tied to a commit or release. They carry an explicit "as-of" marker and must not be read as current state (e.g. `00-inventory.md`, `10-backlog.md`, `16-manuscript-consolidation-matrix.md`, `18-`, `21-`–`25-` review/QA/readiness records).
  - **Live documents** — proposal, pitch, marketing, and reader-segment assets that stay relevant across editions.
- Pre-v2.0.0 documents that still carry the retired "Augmented Development" naming are marked with a historical note at the top.
