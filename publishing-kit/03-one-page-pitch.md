# One-Page Pitch (English)
**Title:** Augmented Development (A-Dev)  
**Hook (10s):** A-Dev is a vendor-neutral framework for AI-assisted delivery. It helps practitioners ship systems they may not fully understand, but can fully validate, by reducing coordination tax with baselines, flags, and a disciplined quality cycle.
**Promise:** A repeatable system to ship production features in short loops with evidence (plan -> prompt -> implementation/tests -> commit), avoiding avoidable debt and tool lock-in.
**Audience:** Individual contributors, team leads, platform and DevEx teams, OSS maintainers.
**Why now:** Speed without guardrails is breaking products. A-Dev provides the missing discipline.
**Differentiation:** Implementation-led theory, living baseline plus quality cycle, short loops behind controlled flags, simple machines, and explicit traceability.
**Structure:** Manifesto -> Role shift -> Atomic Iterations -> Baseline -> Digital Thread -> Quality Density -> Short-cycle delivery -> Practical examples -> Objections -> Appendices (templates).
**Proof:** Release PDFs; CI badges; templates; case studies; repeatable evidence chains from issue to validation.
**CTA:** Start with one feature: apply the quality cycle, update the baseline, publish evidence.
