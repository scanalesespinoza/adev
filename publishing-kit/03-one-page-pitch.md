# One-Page Pitch (English)
**Title:** Augmented Development (A-Dev)  
**Hook (10s):** Stop fighting the AI flood: A-Dev is the framework for the Architect-Orchestrator to ship systems they may not fully understand—but can fully validate—by killing the coordination tax with baseline guardrails, flags, and the 50/50 quality rule.  
**Promise:** A repeatable system to ship production features in 1–2 hour loops with evidence (plan → prompt → commit/tests), avoiding AI-driven debt.  
**Audience:** Solo devs, indie founders, tech leads in SMEs/startups, OSS maintainers.  
**Why now:** 2026 AI debt crisis: speed without guardrails is breaking products. A-Dev provides the missing discipline.  
**Differentiation:** Implementation-led theory (HomeDir lab), living baseline + Broad Quality Cycle, Live Alpha behind flags, Simple Machines (no abstraction tax).  
**Structure:** Manifesto → Solo shift → Atomic Iterations → Baseline → Digital Thread → Quality Density → Weekend Marathon → HomeDir vision → Objections → Appendices (templates).  
**Proof:** Release PDF v0.3.0; CI badges; templates; case studies (Google OAuth + health checks, EvenFlow 6-week experiment → HomeDir).  
**CTA:** Start with one feature: apply 50/50, update the baseline, publish evidence.
