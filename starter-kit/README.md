# Starter Kit

The A-Dev starter kit is the shortest path from doctrine to repeatable practice across repos, teams, and industries.

This is the implementation kit for the [A-Dev practice](../README.md). For agent capability design, also use the [Hardness skill contract](../hardness/02-skill-contract-template.md).

## Adoption path
- [`DAY_0.md`](DAY_0.md): establish the minimum operating skeleton.
- [`FIRST_WEEK.md`](FIRST_WEEK.md): run the first evidence-backed iteration cycle.
- [`FIRST_RELEASE.md`](FIRST_RELEASE.md): close the first release with traceability and verification.
- [`OPERATING_RITUALS.md`](OPERATING_RITUALS.md): compact rituals derived from the execution history of Homedir, the project where A-Dev was first proven.
- [`examples/minimal-adev-loop/`](examples/minimal-adev-loop/README.md): a minimal, repo-agnostic sample to model the workflow.
- [`personal-overlay/`](personal-overlay/README.md): a private layer for one person's working model, evidence, and candidate patterns.

## Existing assets
- [`BASELINE_template.json`](BASELINE_template.json): machine-readable baseline seed.
- [`DECISION_LOG.md`](DECISION_LOG.md): capture decisions and reversals.
- [`QUALITY_CYCLE_checklist.md`](QUALITY_CYCLE_checklist.md): broad quality cycle checklist.

## Use rule
Do not treat these files as theory-only templates. Copy, adapt, and keep them aligned with the actual repository you are operating.
