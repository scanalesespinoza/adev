# Minimal A-Dev Loop Example

This example is intentionally small. It shows the minimum structure needed to run A-Dev in a new repository without depending on a specific tool, model, or Homedir-specific context.

## Included files
- `BASELINE.md`: operating rules.
- `ROADMAP.md`: current next move.
- `prompts/iteration-01.md`: first scoped request.

## How to use it
1. Copy the structure into a target repo.
2. Replace the placeholders with real constraints.
3. Run one atomic change and capture the resulting evidence.
4. Update the baseline with one lesson before starting the next iteration.
