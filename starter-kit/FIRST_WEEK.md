# First Week

Goal: complete a small but fully evidenced delivery loop and learn from it.

## Week 1 objectives
- Run at least one atomic iteration from definition to evidence.
- Capture at least one decision in the log.
- Update the baseline with one concrete lesson.
- Close one walkthrough or smoke-test-backed change.

## Suggested sequence
1. Pick one change with narrow blast radius.
2. Define the expected validation before implementation.
3. Implement in a dedicated branch.
4. Run focused validation.
5. Record evidence: commit, check result, walkthrough note, or smoke test.
6. Translate any failure into a reusable rule.

## What good looks like
- The team can point to one finished loop, not just partial code.
- Prompt quality improved because the baseline was updated.
- The repo now contains a stronger operating rule than it had at the start of the week.

## Avoid
- Chasing many half-finished improvements.
- Treating a green build as the only evidence.
- Leaving important lessons trapped in chat or memory.
